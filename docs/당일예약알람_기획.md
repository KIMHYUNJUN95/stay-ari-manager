# 당일 예약 알람 기획

## 1. 목표
- **Beds24 예약 웹훅**으로 들어온 예약 중 **“당일 예약”**만 골라서  
  **Slack 수신 웹훅(당일예약 전용 채널)**으로 알림을 보낸다.

---

## 2. 정의: “당일 예약”
| 용어 | 의미 | 사용 필드 |
|------|------|-----------|
| **당일 예약** | “오늘(한국/일본 기준) 접수된 예약” | `bookDate` = 오늘 **그리고** `arrival` = 오늘 (당일 예약 = 오늘 접수 + 오늘 체크인) |
| 예약 접수일 | 예약이 들어온 날 | `bookDate` |
| 체크인일 | 입실일 | `arrival` |

- **당일 예약** = bookDate=오늘 그리고 arrival=오늘. **bookDate**: `bookingTime` / `bookTime` / `entryTime` / `invoiceDate` 등으로 계산된 “예약 접수일”.
- **시간대**: 서버/일정은 **Asia/Tokyo (KST)** 기준으로 “오늘” 판단 (기존 일일 리포트와 동일).

**(적용됨)**
- “체크인일이 오늘”인 예약만 알림 → `arrival` === 오늘 (필요 시 옵션으로 추가 가능).

---

## 3. 알림을 보내는 조건 (트리거)
- **진입점**: `beds24BookingWebhook` (Beds24 → 우리 Cloud Function).
- **조건 (모두 만족 시에만 Slack 전송)**  
  1. 웹훅으로 1건 수신 후 정상 처리됨 (upsert 완료).  
  2. `mutationSummary.eventType === "created"` (신규 생성만, 수정/취소 제외).  
  3. `normalized.status === "confirmed"` (확정 예약만).  
  4. `normalized.bookDate === 오늘` **및** `normalized.arrival === 오늘` (당일 예약 = 오늘 접수 + 오늘 체크인).  
  5. (선택) 금액 조건: `getBookingAmount(normalized) > 0` — 무료/취소 건 제외.  
  6. **플랫폼 필터 없음**: 에어비엔비·부킹·수기 예약 등 **모든 플랫폼** 당일 예약에 알람 전송. (다이쿄초 건물만 제외.)

---

## 4. Slack 전송
- **방식**: 기존과 동일하게 **Slack Incoming Webhooks (수신 웹훅)**.
- **URL**: 전용 채널용 웹훅 1개 사용.  
  - 사용자가 제공한 URL: Firebase 환경 변수 `SLACK_SAME_DAY_BOOKING_WEBHOOK_URL`에 설정 (코드/문서에 URL 직접 기입 금지).
- **설정 방법**: Firebase Functions **환경 변수**에 저장 (URL을 코드에 하드코딩하지 않음).  
  - 예: `SLACK_SAME_DAY_BOOKING_WEBHOOK_URL`  
  - 값이 비어 있으면 당일 예약 알람 전송만 건너뛰고, 웹훅 처리(예약 저장)는 그대로 수행.

---

## 5. 메시지 포맷 (제안)
- **채널**: 위 웹훅이 연결된 채널 (예: #당일예약알림).
- **내용 예시** (한 줄 요약 + 상세):

```
🔔 당일 예약 1건
건물: 가부키초 | 객실: 301
체크인: 2025-02-25 | 체크아웃: 2025-02-27 | 2박
게스트: 홍길동 | 인원: 성인 2명, 아동 1명 (총 3명) | 플랫폼: Airbnb
금액: ¥15,000 | 예약ID: 12345678
```

- **인원수**: `normalized.numAdult`, `normalized.numChild` 사용. 성인/아동 구분 표기, 총 인원도 표기.
- **포맷**: Slack `blocks` 또는 단순 `text` 중 선택.  
  - 첫 단계는 `text`만으로 구현해도 됨 (구현 단순).

---

## 6. 구현 위치
| 구분 | 내용 |
|------|------|
| **웹훅 URL 설정** | `functions/modules/slackReports.js` 또는 `index.js`에서 `defineString("SLACK_SAME_DAY_BOOKING_WEBHOOK_URL")` 로 읽기. |
| **알림 로직** | `beds24BookingWebhook` 내부, `upsertReservations` 성공 직후.  
  | 조건: `eventType === "created"` && `status === "confirmed"` && `bookDate === todayKst` → `sendSameDayBookingAlert(normalized)` 호출. |
| **전송 함수** | `sendSameDayBookingAlert(booking)`  
  | - `slackReports` 모듈에 추가하거나, index에 작은 헬퍼로 두고 URL만 params로 주입.  
  | - 메시지에 **인원수** 포함: `booking.numAdult`, `booking.numChild` → "성인 N명, 아동 N명 (총 N명)".  
  | - `axios.post(webhookUrl, { text: formattedMessage })` (기존 `sendSyncAlert`와 유사). |

---

## 7. 예외·에러 처리
- Slack 전송 실패(타임아웃, 4xx/5xx) 시:  
  - 로그만 남기고 **웹훅 응답은 200 OK 유지** (Beds24 재전송 방지).  
  - 필요 시 기존 `sendSyncAlert`처럼 “당일예약 알람 전송 실패”만 별도 채널로 보내는 것은 선택.
- `bookDate`가 null인 경우: 당일 예약으로 보지 않고 알림 안 함.

---

## 8. 체크리스트 (구현 전)
- [ ] 환경 변수 `SLACK_SAME_DAY_BOOKING_WEBHOOK_URL` 등록 (Firebase Config 또는 .env).
- [ ] URL 값: 위 제공 URL 또는 배포 환경에 맞게 설정.
- [ ] “당일” 기준 시간대: Asia/Tokyo로 통일했는지 확인.
- [ ] (선택) 다이쿄초 제외 / Airbnb·Booking만 / 금액 > 0 등 필터 적용 여부 결정.

---

## 9. 요약
- **트리거**: Beds24 예약 웹훅 수신 → 1건 upsert 후, **신규 확정 + bookDate=오늘**일 때만 Slack 전송.
- **대상 채널**: 사용자가 준 수신 웹훅 URL에 연결된 채널 (당일 예약 전용).
- **기획 단계**: 여기까지. 다음 단계는 `SLACK_SAME_DAY_BOOKING_WEBHOOK_URL` 추가 및 `sendSameDayBookingAlert` + beds24BookingWebhook 내 조건 분기 구현.
